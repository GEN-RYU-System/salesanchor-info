# SalesAnchor 案内ページ

B2B営業支援システム SalesAnchor のLP（静的1ページ）。

- `index.html` — 本体
- `shots/` — 画面キャプチャ（inbox / inventory / invoice / orders / analytics / customer .png）
  画像が無い箇所は自動でプレースホルダ表示になるため、後から追加できます。

## 注意
公開ページです。掲載する画面キャプチャは、顧客名・金額・個人情報をマスクしたものだけを置いてください。

## 変更運用

初回公開後の変更は、記録を残すためPull Request経由で行います。
